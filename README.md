## 运行与测试

Node.js 20+，npm start，打开 http://127.0.0.1:4181/ 。默认仅本机访问。游戏无第三方运行依赖。npm install 安装固定 @napi-rs/canvas 0.1.100 后，npm test 运行发布完整性、HTTP 白名单、尺寸几何、六色输入、呈现及缓存回归子集。

18 份原始源码位于内容寻址 builds 目录，根模块为同字节副本；根 HTML 仅调整 CSS 和 app 资源路径。静态运行白名单的 37 个文件由 RUNTIME-MANIFEST.json 绑定。历史构建、测试和 Git 历史保留。

## 变化与验证边界

实际沙粒世界直径为 0.5.2 的 85%，六种颜色，保留既有固定侧缘收窄。冻结 r2 已通过限定云端工程验证：158 项测试、6 条 runtime 路线 1420 次 draw、20736 个 ID 直径对照及六色 120 次动静切换。此处默认测试是发布回归子集，不冒称重跑全部云验证。

综合负载存在回退：累计 draw+flush +28.2%、paint +42.8%、step +51.3%。每帧近似但流动更久。未完成真实浏览器 FPS 验收，不宣称性能无退化或商业质量验收。
