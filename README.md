# 粒序 / GRAINFORM 0.4.1

原创流沙方块网页游戏，使用原生 JavaScript、ES Modules 和 Canvas 2D。

这是0.4.1可见砂砾原型。默认入口保留原版 **96×144**；细沙游戏物理网格仍为 **288×432**。新增颗粒受光与暴露角覆盖，修正空中粒子干扰坡面判断的问题。当前原型以0.4.0整粒色阶版为对照，固定288×432物理网格，仅让可见砂砾覆盖多个细格。静态粒形获准进入验证；CPU密集重画成本未通过，现已准备WebGL2显示后端，实际shader/readback、动态和浏览器性能仍待验证。旧版检查不代表本版通过。详见 [设计与成本](validation/grains-flow-0.4.0/DESIGN.md) 和 [验证协议](validation/grains-flow-0.4.0/VALIDATION.md)。

## 0.4.1 可见砂砾原型

本轮通过随真实材料粒子移动的局部锚点，形成约3–5 CSS px的连续颗粒面。空格保持背景，颜色与物理连通性不变；这是一种可变形表面表示，不是新增刚性大粒子的碰撞模拟。设计和未通过成本见 [范围与验证](validation/surface-grains-0.4.1/README.md)，GPU实现及实际浏览器门槛见 [GPU复验协议](validation/surface-grains-0.4.1/GPU-VALIDATION.md)。

## 0.4.0 历史迭代

- 保持粒数与物理网格，显示层每粒2×2子样本，增加稳定微小明暗、处理暴露边角；空格和八邻接关系不改
- 落块使用短暂、粒子独立的小扰动；坡面只看局部实际接触，保留碰撞路径、密集塌落传播与休眠
- 新增五场景实时0.3/0.4对照，支持只比较材质或只比较运动；同几何、材料与输入，明确区分合成夹具与实玩
- 显示准备有额外成本，部分坡面末端滚落更久；没有据此承诺性能改善或精确物理

第二轮原型基于首轮 `7b94efd`：逐步等价的唤醒缓存及垂直路径优化，配合每八行可暂停的模拟任务，保留全部活动时间欠账；渲染只读已完成的棋盘。新增局部接触明暗和稀疏成对颗粒受光，仍待正常尺寸动态审查。首轮密集唤醒曾出现超过 300ms 的完整回调；新方案的 Node 计时结果不能当作浏览器放行。暂停、输入排队、欠账及原型局限见 [第二轮协议](validation/grains-flow-0.4.0/REVISION-2.md)。

当前显示缓存候选以第二轮 `0e63acab` 为基线，保留相同像素与玩法，仅减少未变化区域的重复栅格计算。视觉目标仍未通过；范围、代价及复验见 [显示缓存说明](validation/grains-flow-0.4.0/CACHE-R3.md)。

本轮基于缓存R3 `5912b53`，把材料变化保留为稳定的整粒哑光色阶，取消格内凸面和孤立强亮点；物理仍为288×432，沿用2×显示及局部缓存。正常尺寸静态对照获准进入动态测试，尚待独立浏览器验收。另修正复用渲染器时换入同版本号棋盘可能残留旧画面的边界情况。详见 [整粒色阶范围与验证](validation/grains-flow-0.4.0/MATTE-PALETTE-PREVIEW.md)。


## 0.3.0 更新

- 清除最高分只有在本地存储写入成功后才报告成功；写入失败会保留已知记录并明确提示，可重试。原版与细沙入口都修复同一问题，使用原有独立存储键
- 细沙界面所有“粒”统一显示实际粒数；计分仍按 9 粒折算 1 单位，规则、分数和等级不变
- 细沙暂停/结束区域的可访问名称与焦点对应当前状态，设置/帮助关闭后保持暂停并恢复到触发按钮
- 页脚与首次刷新提示使用可读文字颜色；首页和帮助明确两壁连通、斜接/空隙与本局不保存

0.3.0当时没有修改粒子物理、八邻接规则、渲染器、音频或性能计时。真实首次玩家测试、真机及屏幕阅读器体验仍需执行；模拟走查不等于真人验证。见 [0.3.0 验证与测试计划](validation/experience-0.3.0/README.md)。

## 本地运行

需要 Node.js 20+。游戏与 Node 自动测试没有第三方依赖，无需执行 `npm install`，也无需构建。

```sh
npm start
```

默认打开 http://127.0.0.1:4173/ 。可通过 `PORT` 环境变量更改端口。开发服务器监听所有网络接口，请只在可信网络使用。

入口：

- `/` 或 `/index.html`：原版 96×144 游戏
- `/preview/game.html`：实验性 288×432 细沙游戏
- `/preview/flow-lab.html`：可选0.3.0或首轮0.4.0作为基线的五场景实时同粒度对照
- `/preview/ab.html`：经典版与当前细沙的历史三场景对照
- `/qa-viewports.html`：原版 CSS 视口模拟
- `/preview/qa-viewports.html`：细沙版 CSS 视口模拟

以上路径带 `.html`，可直接在自带服务器上运行。发布静态站点时提供 `dist/` 中的文件即可；运行时不需要 Node.js 后端。

## 玩法

- 左右方向键或 A/D：移动；上方向键或 W：顺时针旋转
- 下方向键或 S：加速；空格：直接落下
- P / Esc：暂停或继续
- 手机布局提供独立触控键；左右与加速支持长按
- 细沙预览沿用 0.2.1 引入的八邻接：同色沙粒上下左右或斜角相接都算连通；只有同一个连通区域同时接触左右边界才整片消除，空格或不同颜色不会补成连接
- 默认原版 96×144 保留原有四邻接规则，斜角接触不算；规则差异只应用于独立细沙预览
- 新方块的顶部出生区被沙粒堵塞时结束

细沙预览中，消除提示、侧栏及结算均显示真实粒数；每消除 16,200 粒提升一级（最高 20 级）。得分 =（本次粒数 ÷ 9 + 每片 100 分）× 当前等级 × 连锁倍数，最后四舍五入。方块落下得越多也会逐渐加速。

## 自动测试

```sh
npm test
npm run test:preview
```

根测试覆盖原版引擎、输入、界面、存储和跨标签页最高分同步。预览测试覆盖细沙物理、守恒、确定性、冻结0.3参考实现的历史等价、当前材质/空格/缓存及诊断输出。Node 测试不能证明浏览器帧率、视觉体验或真机兼容性。

### 可选浏览器回归

`tests/browser.mjs` 使用 Playwright，对原版进行四种视口下的基础操作、布局、暂停、设置与存储不可用回归。它不执行 20 分钟耐久测试，也不验证实验预览的性能。

可自行安装测试工具与 Chromium：

```sh
npm install --no-save --package-lock=false playwright
npx playwright install chromium
```

先在另一个终端运行 `npm start`，再执行：

```sh
npm run test:browser
```

可选环境变量：

- `PLAYWRIGHT_MODULE_URL`：已有 Playwright 模块的完整 `file:` URL；未设置时导入普通 `playwright` 包
- `CHROMIUM_EXECUTABLE_PATH`：已有 Chromium 可执行文件路径；未设置时使用 Playwright 管理的浏览器
- `QA_BASE_URL`：本地测试服务器地址，默认 `http://127.0.0.1:4173/`
- `QA_OUTPUT_DIR`：截图与 JSON 结果目录，默认 `qa-output/`，脚本自动创建

只对自己有权测试的实例运行此脚本；它会操作页面并修改该浏览器测试上下文内的本地设置。生成的截图、结果、浏览器与测试依赖不随源码快照分发。

## 数据与隐私

游戏仅在 `localStorage` 保存设置与本地最高分，不保存进行中的棋盘。原版与预览使用独立的本地存储键。存储不可用时仍可游戏；未保存的新纪录仅在页面生命周期内有效，之前已保存的记录可能仍保留。清除失败不把已知最高分归零。切到后台会自动暂停，刷新后开始新局。

随附游戏代码没有外部遥测、广告、支付、账号、排行榜、外部字体、外部图片、远程音频或后端 API。音效由 WebAudio 实时合成。静态托管提供方自行注入的代码与服务行为不属于此源码的运行时依赖。

## 诊断与兼容边界

在游戏 URL 加 `?qa` 可启用只用于测试的诊断接口；预览另支持 `?summary` 低干扰累计摘要。计时有自身开销，JS 工作耗时不等于完整浏览器渲染时间，`60 Hz` 固定模拟步长也不等于实际 60 fps。

视口模拟不代表手机真机。手机硬件、Safari、Firefox、真实多指触控、主观音效与 WebMCP 兼容性尚未完整验证。工作名未进行商标检索。
