# 粒序 / GRAINFORM 0.5.1 A 矿砂版

main保存用户选择的0.5.1 A r4试玩源码。包含固定颗粒外观、成功绘制后回执以及上下文绑定的渲染缓存修正；不包含B方形版或0.5.2改动。

## 运行与测试

Node.js20+：npm start，打开 http://127.0.0.1:4181/ 。默认仅监听本机；游戏运行不依赖第三方包。

npm install安装固定版本@napi-rs/canvas0.1.100测试依赖，然后npm test。该命令执行本次发布完整性/HTTP白名单及A版的呈现、后缀绘制、传输回执、粒距与出生回归子集，不冒称完整云验证重跑。

17份原始runtime文件逐字节保存在内容寻址builds目录。根模块为相同副本；根HTML只修改CSS与模块的加载路径。静态部署保留RUNTIME-MANIFEST.json列出的35个资源文件。server.mjs只服务运行白名单。

## 验证与边界

同一冻结构建的云端verify和定向验证已通过；定向对照中已知缓存刷新反例归零，物理位置与回执一致。仍未进行真实浏览器新采样，不保证所有设备持续帧率或商用画质。颗粒内部间隙仍有模糊感，是后续0.5.2设计事项，本基线不夹带修复。

旧构建、dist、既有测试与历史文件保留。旧版本命令是历史工具，不代表当前验收。B私有试玩保持原样；本次GitHub保存不重新部署网站。
