# Independent GPU grid-rank functional prototype

This directory is a copied, independent experiment. Neither the frozen v2 physics core nor the awake-only candidate is modified or imported at runtime. No physics integration, GPU execution in this development environment, shader-compilation pass, speedup, display FPS, or deployment is claimed.

## What is implemented

- Fresh old buckets are actually generated by WebGL2 point/depth peeling, 17 layers, increasing stable slot IDs. CPU-generated buckets are never uploaded as a substitute for the GPU result.
- Old and new anchors use the frozen v2 highp cell-local signed-code encoding. Sparse stable slots remain stable; removed records retain signed-code tombstones and IDs.
- Before each round, CPU reads the actual old anchors and both old atlas textures, verifies unchanged same-generation anchors and complete/valid old membership, and checks the entire proposed next generation. Every alive slot must retain its identity, already be alive, stay in the 58×110 grid, and move strictly less than 4 along each axis. Differences use cell differences plus local-coordinate differences, never absolute-world Float32 subtraction.
- If any qualification is unproved, this bounded prototype stops the whole generation before any rank/scatter draw. New/dead-new slots, revival, reused identity, missing tombstones, duplicate slots, domain escape, unknown/invalid old state, and exactly-4-or-greater motion are not partly mixed with rank output. There is no fallback implementation here; explicit stop is the allowed conservative route.
- A real fragment shader computes every alive particle's rank against all normal 0–15 slots in the old 3×3 neighborhood, in dy/dx/slot order. A separate RGBA32F rank texture retains rank, cell and self-occurrence count for every alive slot, including all 144 members of a nine-cell merge.
- CPU reads the GPU ranks and rejects malformed/self-missing/duplicate-address results before scatter. Two real GPU point draws scatter even and odd ranks into separate new atlases. Rank 16 writes the overflow witness. Rank >16 has no atlas address but remains in the complete rank/particle record.
- All 108,460 queried bucket slots, full rank tuples, per-cell counts, beyond-witness slots, and diagnostics are compared to the independent CPU direct-sort oracle after GPU readback. This checks results; it does not replace GPU calculation. Only a matching, valid result atomically becomes the next generation.
- Overflow or any invalid state permanently stops that object and cannot be cleared by later deletion. A correctly detected overflow case is a successful rejection test, not a valid new grid.

## Storage and GL contract

The grid remains origin (28,-16), cell 4, dimensions 58×110, capacity 16 plus a seventeenth witness. Each atlas is 58×990. The original parity address is `(rank%2, cellX, floor(rank/2)*110+cellY)`.

There are four distinct atlas textures: old even/odd and new even/odd. Rank reads old atlases and writes a separate rank texture. Scatter reads only that rank texture and writes a new atlas. A runtime target/sampler alias check and mock check reject feedback; no regional-feedback exception is used. Every next atlas is fully cleared before scatter, all writes use exact pixel centers and point size 1, and blending/depth/scissor/rasterizer-discard states that could lose or mix output are disabled for these passes.

The only depth-enabled path is initial LESS depth peeling. Initial build has 17 point draws; an eligible reuse attempt has one fullscreen rank draw plus two parity scatter draws. These counts are functional bookkeeping, not evidence of lower GPU cost. This deliberately simple version performs substantial synchronous CPU readback and oracle work; it is NOT the existing no-readback physics step, does not expose a replacement step(), and is not a GPU-resident performance implementation.

Canonical input coordinates are the decoded values of the uploaded v2 Float32 local tuple. The CPU oracle receives these exact same canonical anchors, and reports include the largest initial/upload coordinate rounding difference. Stable cell codes and local highp representation are preserved. No velocities, limits, material forces, or geometry are altered to manufacture a movement-bound proof.

## Run and browser API

Run `npm test` for the preserved 17 CPU contract tests plus prototype eligibility, source, mock-orchestration and whitelist tests. The original CPU test bodies remain, with imports and the read-only core-audit path redirected to bundled frozen snapshots. Mock GL tests use only empty buffers; they neither emulate nonempty GPU physics nor claim shader compilation.

Run `npm start`, default http://127.0.0.1:4178, only in the separately authorized QA environment. This development task did not launch a browser. The page does not auto-run any case or stress test. Buttons select a bounded case, the six core functionality cases, or all 19 bounded qualification/rejection/generation cases.

Browser API:

- `await window.__GRID_RANK_QA.runCase('boundary-crossing')`
- `await window.__GRID_RANK_QA.runSmallSuite()`
- `await window.__GRID_RANK_QA.runAllFunctionalCases()`
- `window.__GRID_RANK_QA.caseNames`, `.results`, `.last`, `.lastSummary`, `.capability`

Low-level API: `await createRankPrototype(gl, oldRecords)` followed by `world.advance(nextRecords)`. Inputs have `{slot,id?,x,y,alive?}`. There is no particle reordering or splicing. `dispose()` releases GL resources. The prototype owns its GL state. External mutation is unsupported except the explicitly enabled, narrowly scoped old-bucket corruption hook used by a QA test.

Named cases include boundary/negative-world-y, explicit deletion, 16/17/144 merge, new slot, revival, identity reuse, strict-four/far motion, duplicate input, missing tombstone, grid escape, old overflow/drift invalidity, a duplicate old GPU bucket, two successful generations with deletion, and an empty generation. No scale sweep or timed performance loop is present.

## Public allowlist and evidence

`PUBLIC-MANIFEST.json` gives SHA-256 and size for each permitted browser file. `server.mjs` serves only that list plus the manifest itself. Source snapshots, Node tests, logs, package files, and arbitrary paths are not public routes. This local allowlist does not publish anything to Sites or another hosting service.

After editing an allowed browser file, run `node make-manifest.mjs` and rerun tests before handing off a frozen candidate. `evidence/node-tests.log` records the local checks. Actual GPU compile/numeric results must be written separately by the authorized cloud QA; do not relabel Node/mock success as GPU success. Bucket correctness, even once demonstrated on real GPU, does not certify physics/material quality or commercial performance.
