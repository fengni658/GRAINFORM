# GRAINFORM 0.4.7 · contact-to-sand candidate

Local candidate based on frozen 0.4.6 SHA210428bf9e2e3cfd07fe3a61ccfb0e4e5107a210. The original 0.4.6 directory is untouched. No push or deployment is included.

Airborne tetrominoes are continuous filled 24×24 cells, with rigid movement and rotation. They do not contain simulation grains. Soft/natural descent and hard drop resolve the first blocked unit of downward movement to a legal subpixel contact pose before atomically admitting exactly676 grains. The old proximity conversion is removed. While the block is airborne, sand candidate endpoints treat its complete silhouette as an obstacle; grains blocked only by it stay in the local active queue so moving/replacing the block does not strand sleeping sand.

Admission fills lower legal cell rows completely and centers the partial upper row instead of punching stratified holes through all rows. Radius0.875, rendered octagon0.870, four colors and169 grains/cell remain unchanged. Free fall prefers a fixed vertical column with alternating half-slot compensation; forced slope descent can shift that column. Downward speed accelerates at900 pixels/s², capped180 pixels/s. A supported edge slip has its own12 pixels/s credit, requires a legal empty side plus a downhill outlet, and must be followed by descent. It cannot crawl over a flat supported plane. This is a lightweight discrete gravity-inspired material rule, not a continuous rigid-body or physically calibrated granular simulation. No explosion impulse, whole-field wake or per-particle rigid solver was added.

The existing seven-piece RNG, controls, normalized score/level, six-neighbor wall connection,24-control-tick clear highlight, pause/restart epochs, retained120Hz clock debt,30Hz publish cap, incremental deltas, stable cache and local radius-two wake remain. Stable fields have zero grain visits. Storage is isolated under grainform:0.4.7:grid keys.

Run `npm test` (41 tests), `npm run verify` (seed1 six and eighteen real game input replays), `npm start` (127.0.0.1:4181; PORT may override). RUNTIME-MANIFEST lists the seven runtime files.
