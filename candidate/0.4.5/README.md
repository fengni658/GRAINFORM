# 粒序 / GRAINFORM 0.4.5 · 独立实验试玩

完整可操作的落块转沙游戏候选，不替换原站或旧0.4.1入口。Node20+，无运行时第三方依赖。

## 运行

- `npm start`，打开服务输出的地址（默认127.0.0.1:4175）。
- `npm test`：真实游戏逻辑、粒数守恒、计分/状态机与物理小门。
- `npm run verify`：seed1实际六块输入的8秒Node回放，4056真实粒子，并逐物理步做几何/支撑审计。该命令会更新 evidence/ 下的验证产物。
- `node tests/replay.mjs adaptive`：显式可选收敛早停核的同场景验证。
- `python tests/render-replay.py`：把真实保存状态画成PNG，需要Pillow。PNG为Node实际状态离线栅格图，不是浏览器截图或FPS证据。

默认使用V7固定迭代快核；URL `?solver=adaptive` 显式选V8双端摩擦检查的收敛早停核。它改变数值轨迹，未声称全场景更快。完整原核SHA记录在manifest。模型未引入法向阻尼外观实验。

## 实际玩法

沿用原七种四格块、旋转踢墙、方向移动、加速/硬降、暂停/恢复、重开、顶部出生堵塞结束。原七块/旋转/RNG直接从逐字节保留的旧preview引擎导入。游戏首次操作即可开始；帮助提供按键和触摸说明。

活动块尺寸24逻辑单位/格。接触底部或已有沙后，全部四格转为676个真实独立圆：每格13行×13粒=169，碰撞半径0.875，显示半径0.870内缩正八边形，无超圈描边。出生采用合法交错行且逐粒确定性水平初速在±1单位/秒内；不是贴图、减少粒数、瞬移散开或固定沙格。后续完全交回连续位置物理。网格CELL1.8只做邻居搜索。四色同材料，不设层隔板。

活动块的自动接触使用小于粒半径的0.75单位预接触保护带，在沙的下一次物理更新前转沙，避免把活动块当作可穿透覆盖图；已有沙粒不被为此移动或删除。硬降逐单位检查，出生位置在整个合法块轮廓内部。不存在旧草稿的向上48单位搜位修正。

同色沙粒必须通过真实圆接触（直径1.75+0.012接触容差）形成一个同时触及左右墙的连通区，才整片消除。网格候选、不同颜色和真实空隙不能桥接。0.2秒消除闪烁期间冻结物理及锁定身份；随后用核心remove逐粒移除，正确唤醒支撑依赖并自然下落。粒数守恒：已生成数=现存数+真实消除数。

计分保留原游戏每格64归一面积单位、每四格块256单位。新每粒折算64/169单位，避免因颗粒尺寸改变把每块价值降低。得分=(本次归一面积+100×连通片数)×等级×连锁数，四舍五入；每1800归一单位升一级，最高20。硬降每完整24单位奖励2分。界面“粒”统计使用rawCleared；cleared保留向下取整的归一面积字段。0.4.5记录使用独立存储键，不覆盖旧最高分。

## 性能及已知边界

这是实验试玩：密集场面可能变慢，堆积可能偏陡或短暂保留块的轮廓，并非已认证的自然流体/正式60FPS版本。半径与粒数不随负载偷偷调整，不能用升配GPU自动加速CPU求解器。

真实物理在Web Worker中，主线程Canvas逐粒画八边形；输入和界面不在同一物理长任务内。Worker每回调有界固定步，过载主动放慢游戏时钟，不建立无限追赶队列、不跳过中间物理状态、不丢已经生成的沙粒。该时间膨胀是明确的实验时钟策略，界面报告实际模拟倍率/处理耗时；不声称模拟时间等于墙钟。输入按序送入Worker，暂停/重开以Worker确认状态为准。

内核是平移圆粒、简化耗散摩擦和有依赖唤醒的局部休眠，没有刚性转动或完整力平衡证明。支持的单粒输入速度有界；游戏不向核心注入极端外力。满场/手机硬件/真实浏览器帧率以独立QA报告为准，不能从Node回放推断。
