## 浏览器视觉与性能门槛

1. 在正常尺寸和较小视口逐个看完整过程，保留基线、候选以及不利时刻；不挑重跑或只看静帧
2. 检查颗粒层次、边缘台阶、独立飞散粒、同色细连接及真实空隙；既要减少方格感，也要避免模糊、液体表面、粘连或闪烁
3. 停料后应逐步收稳并静止，允许少量末端滚落；记录最终活动粒与分块。三种对照模式下切换/重播/暂停/继续无残影
4. 普通游戏验证方向/旋转/落下、八邻接及负例、清除/连锁、暂停设置、存储失败、0.3提示底板对比度；语义和数据不能因新视觉回退
5. 单页普通游戏单独测性能，不用双侧实验室帧率代替。记录完整callback、分阶段render/physics、gap、输入响应、冷音频启动与坏帧；诊断开/关成本与物理密度明确标注
6. 桌面浏览器通过不等同实体手机、音效听感或屏幕阅读器完整游玩通过。不得据Node微基准或采样图片声称稳定60fps
