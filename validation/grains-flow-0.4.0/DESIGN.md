# 0.4.0 颗粒、轮廓与连续流动设计

原始基线：`9b7a889658c742c8598e927543817e8ab20f20aa`（0.3.0）。本文件保存首轮设计。当前源码还包含基于首轮 `7b94efd` 的第二轮修订，见 [REVISION-2.md](REVISION-2.md)；以下首轮成本和检查不能代替第二轮结果。当前状态仍为未放行原型。

## 观察与可复现原因

0.3.0 的实际动态基线在正常棋盘尺寸下呈现细微纹理，但大面积更像平色填充；落地形成尖锐楔形，外轮廓有规律小台阶。坡上新沙像连续薄色带；同时抽走整条底层时，分层堆的下缘一度保持平直。这些是视觉观察，不自动证明所有运动违反物理。

源码中每粒只有一个完整着色像素，顶面整格增亮，再把整板放大。材料明暗跨度较窄，轮廓也沿完整方格展开。一次落块释放给全块粒子按方块中心同向向外的速度，能量32可在约0.267秒内绕过坡度门槛。

更明确的因果问题来自坡面判定：它使用整列最顶端的粒子作为表面。在局部支撑完全不变时，远处或正上方尚未接触的空中粒子就能阻止坡上沙粒滚落。三个小夹具分别覆盖四格外坡度、三格外长步和正上方暴露判定；0.3的结果受空中粒子影响，原型的结果保持一致。

同时失去全部支撑的理想自由落体可以暂时保持形状。因此本轮保留密集层的支撑传播，避免恢复内部空气梳缝；不为打碎外观而加入随机抖动或破坏质量。

## 采用的设计

1. **材质**：物理粒子仍为288×432。每粒在显示缓冲中使用2×2子样本，稳定材料编号决定微小明暗和受光面，纹理随粒子移动；停止后不闪烁或继续扰动。
2. **边缘**：只在暴露颗粒的角内做覆盖度处理，空物理格保持背景，不补洞、不扩大连接。相同颜色斜角相接的共享角保留实色，以对应八邻接规则。内部细节保持清楚；没有整图模糊、液体融合或水面反光。
3. **释放与流动**：落地释放改为各粒独立的小幅水平扰动，量化速度范围−4至4、能量8。三个坡面/暴露判断改查同高度附近的真实占据，而不是全列最高点。支撑传播、逐格路径碰撞、休眠和刚体不可穿透条件保留。

只增加显示采样比增加物理网格更容易约束成本；更高物理密度、连续位置粒子求解和大规模压力模型暂不引入。当前仍是有摩擦与睡眠的格点沙粒近似，不能称精确物理模拟。

## 成本与取舍

- 物理没有新增网格或粒子数，材料/速度等数组数量不变
- 单份ImageData由497,664增加到1,990,656字节（4倍）；显示Canvas也相应变大。新增调色表总共131,072字节，ready几何缓存124,416字节。Canvas实际内存仍须浏览器测量
- 空格统一填底色后，仅对占据格计算四子样本。固定密度、交替顺序的Node准备测试中，10%密度旧/新mean约0.65/0.54ms，50%约0.89/1.43ms，85%约1.16/2.22ms。85%新p95约4.41ms、max7.13ms。Canvas上传和合成在此测试中为no-op，不能据此推算浏览器帧率
- 初版未批量填背景的较慢样本已保留；不删除高耗时记录。计时是共享环境中的墙钟，不是CPU采样
- 顺坡末端会比旧版多一段少量粒子滑落，不能宣称收稳更快。五场景均须最终睡眠，继续运行不得漂移

## 未完成的验收

原型还没有通过真实浏览器的动态视觉评审。应确认新细节像干沙而不是噪声/亮片，轮廓自然且无水滴融合，薄连接与真实空隙可辨，流束在接触时局部滑落、稳定核心不液化，并在正常/高辨识两种模式下检查。还需测真实上传/合成、完整回调、输入响应与手机成本。0.3的检查不能冒充0.4通过。
