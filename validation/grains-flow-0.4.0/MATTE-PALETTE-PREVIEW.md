# 288网格整粒哑光色阶：待真实动态复验的有界原型

基线5912b53ee6a166a729ec4045009720199cbfc952。运行时主要改grain-raster.js，并修正渲染器换入另一棋盘时的重画检查；物理、调度、输入、缓存算法、显示倍率及普通游戏界面保持。正常游戏仍288×432，显示2×，ImageData仍1,990,656字节。

每种普通颜色冻结四档同色系哑光色阶。256种材料种子映射到26/76/102/52个色档，不包含时间或坐标噪声。整粒四个主体样本保持相同平均色，不再画内侧凸面、整圈暗边或稀疏亮点；自由边界的最多±3局部受光及角内覆盖保留。不同颜色相接不额外绘制分隔暗线。

首次直接按材料编号分档，把注沙夹具的线性编号顺序显现为条带。最终仅加入固定种子置换，颜色和色档数量未改，避免把编号顺序误当亮度。置换不使用游戏随机流。

352/428px A/B使用同一个完成的物理状态，左为缓存R3，右为本原型；使用离线栅格缩放，并非浏览器截图。正常尺寸静态审阅认为色差更连贯、没有新增144网格阶梯或白亮点，获准进入成本/功能和真实动态验证。它不构成立体体积、摄影真实感或最终动态视觉验收的结论。

本原型借鉴一手项目中“稳定材料值随粒子移动”的组织方式，没有复制外部源代码或美术。它仍是一项需感知验证的假设，不因参考项目存在就保证效果。

## 正确性与重画检查

最终源码回归：原版50/50、细沙109/109、61个JavaScript/ES Module语法检查通过。原版9个发布文件、细沙引擎、应用逻辑及普通游戏界面与缓存R3保持逐字节一致。

独立检查核对196,608个局部颜色邻域、1,048,576个调色样本以及500帧脏缓存输出。真实空格始终背景；覆盖仅混合本格颜色与背景，同色斜角接点保留，异色之间不生成颜色桥或额外分隔暗线。材质的依赖范围只需相邻3×3，原8格瓦片扩展仍保守有效。21种活动块形色组合的移动/落地材质保持，以及高辨识/减少动态转场通过原始字节检查。

另发现并修复继承自R3的边界：同一渲染器换入不同Game对象，若尺寸、state和gridVersion恰好相同，内部重画判断可能沿用旧图。现在额外检查对象身份；回归先复现失败，修复后与新建渲染器完整输出一致。这不是对旧长帧根因的解释。

## 浏览器复验入口和停止条件

`/preview/flow-lab.html`默认左侧缓存R3，双方物理/材料状态一致；依次看注沙、顺坡、边缘塌落、收稳和消除塌落，正常/高辨识与暂停切换都检查。材质应随真实粒子移动，停止后不爬动或闪烁；同色细连接、异色接触和真空隙仍可辨。不以放大裁切替代正常352/428px棋盘，也不用双侧实验室计时代替普通游戏。
