## 真人首次玩家脚本（未执行）

建议5位此前未玩过GRAINFORM的目标玩家，每位10–15分钟。记录匿名编号、设备/OS/浏览器、输入方式、方块游戏经验。先限定计划支持平台；小样本不能代表总体。

开场：“测试游戏是否容易理解，不是测试你。请说出你在想什么。我暂时不解释规则，你随时可以查看游戏内帮助。”

1. 请开始游戏，试试移动、旋转和让方块落下。记录开局耗时、求助、帮助路径、误触；不提前解释消除规则
2. 请试着完成一次消除。从开局计时最多5分钟，允许应用内帮助。2分钟无进展且主动求助时只提示可以打开玩法，并单独标记主持人提示，不计入无口头提示成功
3. 尝试后问消除条件，并给三个固定示例预测：同色斜接贯通两墙；唯一通路有一格空隙；两墙同色但不连通。追加问异色阻断，记录原话，先预测后解释
4. 请暂停、打开设置、关闭并继续。观察误以为关闭自动恢复、找不到继续或误重开。键盘参与者全程键盘；辅助技术另由有真实使用经验者验证
5. 刷新前问哪些内容留下，记录预测，再明确刷新会结束本局并在测试页面操作。检查是否理解设置/最高分与棋盘的区别
6. 若没有自然结束，不无限等待；可另开明确标记的合成结算任务测试再玩，不能算自然游戏时长

建议目标：至少4/5人在30秒内无口头指导开局；至少4/5在首次尝试后正确解释左右同一区域、斜接和空隙/异色三个条件；至少4/5在5分钟内借助应用内提示完成一次消除，且无主持人口头教学；至少4/5正确预测存档边界。未达标先定位文字、发现性或输入问题，不据小样本直接改随机/调速。

功能条件另外核实：全部所测键盘流程无焦点陷阱或隐藏焦点，关闭对话框不自动恢复，暂停/结算区域名称正确。棋盘仍依赖视觉，不宣称支持完整非视觉游玩。
