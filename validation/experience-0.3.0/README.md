# 0.3.0：记录失败反馈与体验细节

基线：`282afdcbc2f21f74fe8429b025e7598f99a1cb7e`。本文件描述独立源码候选，浏览器复验与发布须绑定后续精确提交。

## 改动边界

- 原版与细沙入口都修复清分写入失败仍归零并播报成功的问题。写入成功才清零；失败保留已知最高分，显示文字并使用既有单一 aria-live 播报。初始读取被拒绝时无法显示未知旧值，但不会声称清除成功
- 失败时可读取另一标签页的更高记录，不降低已知的内存最高分。之前未保存的新纪录仍可能仅存在本页，不能宣称刷新后保留。成功清分不因暂停局得分未变化而立即回写；之后获得新分数仍可建立新纪录
- 按存储键保留失败标记，成功清分不能掩盖未保存设置；取消不写入，失败可重试。既有存储键不变
- 细沙“粒”使用真实数量 rawCount/rawCleared。计分仍为 `(raw / 9 + 100 × regions) × level × chain` 最后四舍五入；等级仍为每16,200粒一级，上限20，等级条按真实粒数显示
- 首页、暂停、结束区域名称分别对应状态。暂停聚焦继续，结束聚焦再玩，开始/恢复聚焦棋盘；背景暂停不抢焦点。关闭设置/帮助保持暂停，优先返回可见触发按钮；按钮因媒体查询隐藏时返回当前状态的主操作
- 页脚与刷新提示采用主题文本变量：普通 #899494、高辨识 #a9b4b1 对背景 #121718 的对比度均超过4.5:1。此结果不构成全站可访问性认证
- 首页简述同色连通两墙与斜接/空隙；帮助明确加速/直接落下区别、粒数与计分单位及本局不保存。无强制教程或新存储标记

经典入口仅同步存储缺陷，保留经典规则、样式及其他文案。物理、连通、渲染、音频、输入与性能诊断模块不变。
