# GRAINFORM 0.4.1 · 较大可见砂砾原型

基线：f9f38953ab94d8fd0df591c3749d8839fe34337b。固定288×432物理格、已有碰撞/摩擦、八邻接、输入、调度、计分、存储及音频。0.4.1只改变显示层的可见颗粒规模。原版96×144入口保持。

约八分之一的稳定材料种子作为移动锚点。材料随真实粒子传递；每个2×显示子样本选同色邻域中最近和次近锚点，形成约3–5 CSS px的连续颗粒面。每片采用一个完整哑光色阶、宽面受光和短接触阴影，不在小格上重复画环。真实空格保持精确背景；不同颜色不相互着色，同色斜角接点保留。锚点选择不使用物理随机数，不新增粒子身份或碰撞约束。

这是可变形的表面表示：剪切时局部归属会改变，不承诺每个可见面是独立刚性砂粒。稀疏处无锚点的约1.3–1.4%子样本回退已有细粒画法。极小部分锚点可影响空隙另一侧的同色区域，但空隙本身从不被填充。这两处需要正常尺寸动态观察是否闪动或产生不合理跟随。

本阶段最终回归：原版50/50、细沙118/118、67个脚本语法检查通过。

正常352/428px同状态离线对照已实际审阅，较大颗粒轮廓清晰，获准进入动态验证。没有真实浏览器动态验收结论。

距离/面部明暗预表、复用缓冲和局部脏区已实现；依赖半径各向4格，局部输出使用完整外扩来源重算winner及runner-up。独立原始逐样本算法、平移/静止、空格/色界/斜角、clear/contrast/motion、sprite及状态生命周期检查通过。独立213个缓存案例中204次走局部路径；完整输出逐字节一致。后续新后端必须重新证明这些条件。

## 下一阶段与验收

有界WebGL2显示计算后端已实现为待验候选，使用最近/次近锚点竞争和冻结的着色参数，CPU保留为参考与不支持时回退；物理保持不变。需验证整数纹理、深度同距顺序、单色对称锚点、所有图形/色界/空格、context loss/recovery和不支持回退。

渲染后端性能必须区分CPU命令提交、GPU实际完成及首个可见变化，不能用提交耗时充当完成耗时。正常352/428px五场景视频检查大颗粒随材料移动、剪切只局部重组、静止无爬动/闪烁；再做普通页真实输入和密集唤醒完整callback、欠账及模型年龄检查。软件WebGL与硬件GPU结果分别标明。未经这些验证不能视为浏览器性能或动态视觉验收通过。
